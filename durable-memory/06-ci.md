# 06 — Continuous Integration and Release

`.github/workflows/ci.yml` builds and runs `./test.sh` across all 5 target platforms:
- `linux-x64` (`ubuntu-24.04`)
- `linux-arm64` (`ubuntu-24.04-arm`)
- `macos-arm64` (`macos-14`)
- `macos-x64` (`macos-15-intel`)
- `windows-x64` (`windows-2022`, MSYS2 MinGW64 static toolchain)

On `v*` tags, the `release` job packages and publishes all 5 static binaries to the GitHub Release.

## v0.2.0 release (2026-10-23)

Main grew the post-review API surface (new filter operators, TCP options, DNS fields, TLS 1.0/1.1
builders), which 9 of the 19 README autorun captions require, so the minor version moved 0.1.1 ->
0.2.0 in `CMakeLists.txt` (`project(lmshark VERSION ...)`) and the `LMSHARK_VERSION` fallback in
`cpp/main.cpp` (the schema and THIRD_PARTY_NOTICES carry no version string). One example fix was
needed first: `tls_version_census.lms` used `font ',10,Bold'`, which lmplot v0.2.0 (fail on
gnuplot warnings) rejects as an invalid font size; it now uses `font ',10'`. `test.sh` (18
checks) passes locally with lmplot 0.2.0 on PATH. Autorun verification of the README captions
against the published release is recorded after the release job attaches the 5 binaries.
