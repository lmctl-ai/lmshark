# 02 — Libraries and Licenses

- **Host & Core Engine (`cpp/shark.hpp`, `cpp/shark.cpp`, `cpp/main.cpp`)**: Original MIT-licensed C++17 implementation.
- **Third-Party Source Dependencies (`deps.lock`)**: None. Zero GPL/LGPL code is used or linked.
- **Runtime Notices (`THIRD_PARTY_NOTICES`)**: Documents the MIT license of `lmshark` and the platform runtime libraries (dynamic glibc >= 2.35 on Linux, static libstdc++/libgcc with the GCC Runtime Library Exception, macOS system libraries, and MinGW-w64 static runtime on Windows).
